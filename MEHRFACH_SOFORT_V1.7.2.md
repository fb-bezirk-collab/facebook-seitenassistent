# Mehrfach sofort veröffentlichen – Version 1.7.2

Auf der Entwurfsseite können mehrere Facebook-Seiten ausgewählt werden.

Danach stehen zwei Aktionen zur Verfügung:

1. Ausgewählte Seiten planen
   - Datum und Uhrzeit sind erforderlich.
   - Jede Seite erhält den zugewiesenen Text.

2. Auf ausgewählten Seiten sofort veröffentlichen
   - Kein Termin erforderlich.
   - Jede ausgewählte Seite wird unmittelbar veröffentlicht.
   - Die jeweilige Textzuweisung wird berücksichtigt.
   - Erfolg und Fehler werden anschließend im Entwurf angezeigt.
