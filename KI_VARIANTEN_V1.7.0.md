# KI-Textvarianten und Seitenzuweisung – Version 1.7.0

Die KI erzeugt sechs eigenständige Facebook-Texte.

Ablauf:
1. Beitrag importieren und als Entwurf speichern.
2. Im Entwurf sechs KI-Varianten erzeugen.
3. Entwurf speichern.
4. Bei der Planung für jede Facebook-Seite eine Textvariante auswählen.
5. Optional „Varianten automatisch verteilen“ verwenden.
6. Jede Planung speichert eine eigene Textkopie.

Bereits geplante Texte ändern sich daher nicht automatisch, wenn später
neue KI-Varianten erzeugt oder der Haupttext geändert werden.

Railway-Variable:
OPENAI_API_KEY

Optional:
OPENAI_MODEL=gpt-5-mini
