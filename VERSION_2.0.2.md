# Version 2.0.2 – Manueller Import korrigiert

Behoben:
- KI-Funktion steht nach manuellem Medienupload zur Verfügung.
- Der manuelle Upload kann als Entwurf gespeichert werden.
- Bilder, Videos, Text und Quellenlink werden an den Entwurf übergeben.
- KI-Varianten sind bereits vor dem Speichern direkt bearbeitbar.
- Bearbeitete Varianten werden im Entwurf gespeichert.
