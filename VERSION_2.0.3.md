# Version 2.0.3 – Manueller Upload stabil

Der manuelle Upload verwendet jetzt denselben stabilen Ablauf wie alle
anderen Entwürfe:

1. Medien und Text eingeben.
2. Upload absenden.
3. Der Entwurf wird sofort angelegt.
4. Automatische Weiterleitung zur Entwurfsseite.
5. Dort sind Text, Medien und KI sichtbar.
6. KI-Varianten können direkt bearbeitet und gespeichert werden.

Damit erscheint jeder manuelle Upload sofort in der Entwurfsliste.
