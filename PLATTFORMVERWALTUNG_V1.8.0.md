# Plattformverwaltung – Version 1.8.0

Die Kontenverwaltung wurde von einer reinen Facebook-Liste auf eine
allgemeine Plattformstruktur umgestellt.

Unterstützte Plattformdefinitionen:
- Facebook
- Instagram
- X
- TikTok

Aktueller Funktionsstand:
- Facebook-Konten werden weiterhin automatisch über Meta übernommen.
- Facebook-Veröffentlichungen funktionieren unverändert.
- Instagram ist als eigene Plattform vorbereitet.
- X und TikTok sind als spätere Plattformen vorbereitet.
- Manuell angelegte Konten werden eindeutig als noch nicht
  veröffentlichungsfähig gekennzeichnet.

Nächster Schritt:
- Verknüpfte Instagram-Business-Konten aus der Meta Graph API auslesen.
