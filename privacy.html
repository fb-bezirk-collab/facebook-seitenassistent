Datenschutzerklärung

Diese Datenschutzerklärung informiert über die Verarbeitung personenbezogener Daten im Zusammenhang mit der Facebook-Anwendung „Facebook Seitenassistent“.

Zweck der Anwendung

Die Anwendung dient ausschließlich der Verwaltung von Facebook-Seiten, für die der jeweilige Benutzer selbst eine Berechtigung erteilt hat. Sie ermöglicht insbesondere das Erstellen und Veröffentlichen von Beiträgen über die offizielle Facebook Graph API.

Welche Daten werden verarbeitet?

Die Anwendung verarbeitet ausschließlich jene Daten, die für die Nutzung der Facebook Graph API erforderlich sind. Dazu können insbesondere gehören:

  • Facebook-Seiten-ID
  • Seitenname
  • Facebook-Zugriffstoken (Access Token)
  • Beiträge, die über die Anwendung veröffentlicht werden

Es werden keine personenbezogenen Daten verkauft, an Dritte weitergegeben oder zu Werbezwecken verwendet.

Speicherung von Daten

Die Anwendung speichert personenbezogene Daten nur, soweit dies für den technischen Betrieb erforderlich ist. Es erfolgt keine dauerhafte Speicherung von Facebook-Zugangsdaten, sofern dies nicht ausdrücklich für zukünftige Funktionen notwendig wird.

Weitergabe an Dritte

Eine Weitergabe personenbezogener Daten erfolgt nicht. Die Kommunikation mit Facebook erfolgt ausschließlich über die offizielle Facebook Graph API.

Rechte der Nutzer

Nutzer können erteilte Berechtigungen jederzeit über ihre Facebook-Kontoeinstellungen widerrufen.
