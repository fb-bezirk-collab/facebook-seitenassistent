# Facebook-Seitenassistent

Dieses Projekt dient der Entwicklung eines Facebook-Seitenassistenten.

Geplante Funktionen:

- Beiträge automatisch auf mehreren Facebook-Seiten veröffentlichen
- KI-gestützte Textanpassung
- Zeitgesteuertes Posten
- Bild- und Videoverwaltung
- Unterstützung mehrerer Seiten


## Version 1.2 – Veröffentlichungsplanung

Unter **Einstellungen** können Social-Media-Konten angelegt werden. Verbundene Facebook-Seiten werden automatisch übernommen. In jedem Entwurf lassen sich mehrere Veröffentlichungen mit Plattform, Konto, Datum, Uhrzeit und Status anlegen. Die Übersicht **Planung** zeigt alle Termine chronologisch. Version 1.2 plant und verwaltet Veröffentlichungen; das automatische Senden an Facebook folgt in Version 1.3.
