# Facebook-Seitenassistent

## Version 1.3 – Facebook-Verknüpfung

Funktionen:

- geschützter Login für den Seitenassistenten
- Import bestehender Facebook-Beiträge
- lokale Speicherung von Bildern im persistenten Railway-Volume
- Entwürfe und Veröffentlichungsplanung
- OAuth-Verknüpfung mit Facebook
- Abruf des verbundenen Facebook-Kontos und der verwalteten Seiten
- Aktivieren und Deaktivieren einzelner Facebook-Seiten
- dauerhaftes Speichern der Tokens und Seitendaten unter `/app/storage/data`
- Verbindung erneuern und vollständig trennen

Die eigentliche automatische Veröffentlichung auf Facebook wird im nächsten Entwicklungsschritt ergänzt.

Die Einrichtung der Meta-App ist in `FACEBOOK_VERKNUEPFUNG.md` beschrieben.
